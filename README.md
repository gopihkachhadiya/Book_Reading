# Vachanamrut Study App

A React Native mobile application for studying the Vachanamrut, a principle scripture of Swaminarayan Sampraday. This app provides an intuitive interface for reading, listening to, and studying the divine discourses of Bhagwan Swaminarayan.

## Features

- **Scripture Reading**: Access to 273 spiritual discourses with easy navigation and search functionality
- **Audio Playback**: Listen to audio recordings of the Vachanamrut
- **Bookmarking**: Save and organize your favorite passages
- **Study Tools**: Access definitions, explanations, and references
- **Customization**: Adjust font size, theme, and reading preferences
- **Offline Access**: Download content for offline reading

## Getting Started

### Prerequisites

- Node.js >= 18
- React Native development environment setup
- Xcode (for iOS development)
- Android Studio (for Android development)

### Installation

1. Clone the repository:
```sh
git clone <repository-url>
cd Book_Reading
```

2. Install dependencies:
```sh
npm install
```

3. Start Metro bundler:
```sh
npm start
```

4. Run the app:

For iOS:
```sh
npm run ios
```

For Android:
```sh
npm run android
```
